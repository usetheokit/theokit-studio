## Prova de vida do defeito que dá nome ao milestone

O M7 existe para tirar inverdade da documentação — e a review provou que eu tinha **introduzido**
uma inverdade nova ao consertar as antigas. A trava contra isso foi exercitada **na própria tag**:
mutando o hero do README de volta para *"Describe an agent in plain language and get a working
agent file back"*, o teste de contrato fica vermelho (`1 failed | 6 passed`). Mutante revertido.

Isto é o que separa este milestone do estado anterior: antes, a única proteção contra o README
mentir era revisão humana — e ela deixou passar o corte de 20 telas.
